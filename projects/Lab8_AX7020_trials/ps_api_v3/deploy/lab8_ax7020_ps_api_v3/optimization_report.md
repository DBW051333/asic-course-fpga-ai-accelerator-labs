## 热点、原型与选择

重新剖析当前 v2（parent_driver 为 v2 原样副本），不是沿用 v2 目录中的旧 v1 profile。100 次 N42 cProfile 完整路径约 215 ms，infer_batch 自身约 51 ms，三次 any 累计约 19 ms；仅用于归因，受剖析开销影响，不作性能验收。

初始预算两个小原型：P1 用显式小端 uint64 字掩码合并非法 class/padding 检查，并取消整包中间拷贝；P2 用 Struct("<BbbBI") 一次解码类别、两个 signed score 和五个 padding 字节。P2 的记录迭代在大 N 会变慢，因此补测交叉点并做必要的混合集成。

微测在本板上使用合法的合成 8 字节响应（score 8/-11），每版本两块各200次、每块预热20次，不包含 DMA/MMIO/统计，只用于选择交叉点。N48 记录解码仍明显更快，N64 接近持平；因此正式 A/B 前固定保守规则 N≤48 使用记录解码，N>48 使用整字校验。未根据正式测量挑选最佳 N 或改收益目标。

所有实际响应长度、class 范围、signed score/class 一致性（平分归0）、五个 padding 字节、两个硬件字节计数均保留；四个当前硬件统计逐一读取，不缓存旧值，不用数组切片假装硬件快照。predictions/scores 仍是独立可写副本，后续 DMA/扩容不会覆盖旧结果。

DMA 启动、flush/invalidate、实际长度、有界等待、错误优先于 Idle、异常后 reset 均与 v2 保持原样；AST 核对除 infer_batch 外全部方法一致，scalar 路径未改。追加预算用于两个原型混合集成、分支边界和 N256/512 正式测量，无 RTL/模型/时钟修改。

## 新执行的功能与可靠性检查

15 项主机回归通过，保留原12项并补充 signed -128/-127/-1/0/1/126/127 及平分、N48/49 分支、每个 padding 字节及类别高位、非法实际长度、当前统计值变化、可写快照跨 DMA/扩容有效。另独立标量参考 48 输入/7776 值通过，课程准确率仍只统计42个输入。

实板 42/42 分类正确，6804 个逐层特征逐值一致；多种整数类型、非连续/Fortran 输入、可变输入、结果寿命、非法输入、连续批量、截断包、reset 和 Overlay reload 通过。

120 秒持续实板测试完成 33449 批事务，3398008 次重复课程输入，额外 108216 个特征值检查，硬件错误0。覆盖 N=1/2/3/8/16/42/48/128/256/512。该事务数含检查/特征回读，不作纯 API 吞吐。

虽未修改 DMA，仍重新运行两种真实故障回归：实际启动接收而不发送触发有限超时；168字节物理缓冲声明8字节容量接收162字节特征包触发 S2MM 长度错误。两次均自动复位并恢复完整42样本分类/分数一致，未使用无效物理地址。

- real_receive_pending_timeout：故障前状态 {'send': '0x1002', 'recv': '0x1000'}，恢复通过。
- real_s2mm_length_error：故障前状态 {'send': '0x1001', 'recv': '0x5011'}，恢复通过。

## 硬件、部署与实际范围

RTL/权重/bit/hwh/XSA 与 v2 相同；FC1 192路全DSP，DSP212，PL单时钟寄存器推算 142.857141 MHz。核心216拍，N42 PL事务7337拍。本轮未重新综合或布局布线，无新增硬件周期/资源收益。

LUT14299、FF18905、Slice5791、BRAM36等效56、DSP212、WNS +0.229ns/WHS +0.026ns 是原AX7020硬件实现证据复用。现用Boot/FSBL不变；PYNQ默认50MHz参考的214.285714MHz不用作实频，沿用SLCR/tick核查。地址范围覆盖现用高DDR缓冲，不等于全DDR压力测量。
