## 数据与证据

- `versions.csv`：便于比较的指标表；空项表示未从结构化数据取得，不能当作 0 或未通过。
- `report_measurements.csv`：逐份提取的资源/时序测量，注明设计状态和原报告路径，避免把不同约束或综合/布线数据混为一条。
- `versions.json`：每版配置、运行状态、全部本地 JSON 快照、中央汇总原记录及其路径、错误摘录和报告索引。不同日期/约束/综合与布线口径不可混用；中央汇总可能过期，原日志与最后的 run_status/final_clock 优先。
- 每版 `.tar.gz`：输入与权重数据、配置 JSON/XDC、数值输出、日志、资源及时序报告、说明。仅记录数据；不保留未选中版本的 RTL/TB/XPR、DCP、波形与构建数据库。
- `file_inventory.json`：删除前所有文件大小、SHA-256、时间、哪些内容进入记录以及哪些共享依赖需继续存在。
- `context/`：各轮完整比较数据、量化范围证明、资源演进及停止判断，保留原始口径。
- `protected_dependencies.json`：被保留工程引用的文件及共享工具、数据，不作为额外工程版本。
- `cleanup_receipt.json`：在本地和 GitHub 记录均通过校验后执行的删除清单与空间统计。

本次未重跑功能仿真或布局布线，不把仅数值正确、未完成试验或历史标题中的 recommended 作为当前最佳。代表工程按已核实的最终记录选择。保留工程中的历史对比/搜索脚本若依赖被移除的旧工程，需要查阅本记录；正常代表版本的源码和初始化数据依赖保留。

大部分版本的原始数值/资源数据已保存；对于从未生成报告或已缺失的测量，本记录明确留空，不虚构结果。用户需要进一步追溯时，应查看对应压缩包内的原始报告。
