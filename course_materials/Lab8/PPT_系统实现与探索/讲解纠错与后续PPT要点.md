## 2026-10-19：权重量化与 DSP 双乘积打包需单独解释

用户反馈：现场对权重打包的解释有误，后续重做 PPT 时需要将此作为独立讲解点。该要求已在2026-10-19的v21中落实，见文末交付记录。

- 区分两个阶段：浮点权重通过缩放、舍入和范围限制量化为 INT8；随后才将两个 INT8 权重打包供 DSP 计算。量化不改变矩阵维度。项目实际量化尺度与粒度须核对量化脚本后表述。
- 固定下标定义：a_i = sum_j W_ij x_j + b_i，行对应输出神经元，列对应输入。
- 核心配对关系：同一输入、不同输出的两个权重配对。例如 W11 与 W21 共享 x1；W12 与 W22 共享 x2；W13 与 W23 共享 x3。用矩阵同列高亮和两个累加器的箭头说明。
- 数学构造：W_pack = W_1j + 2^16 W_2j；P = x_j W_pack = x_j W_1j + 2^16 x_j W_2j。
- 两个乘积经位段提取和符号修正后，分别进入输出 1、输出 2 的累加器；遍历输入后各自加偏置。
- 必须解释负数造成的高位修正；打包是有符号算术构造，不能笼统描述为直接拼接两个 8 位数。
- 相邻输出行仅为教学示例；实际硬件配对、移位宽度和提取逻辑须核对当前工程 RTL，再标注为项目实现。

建议后续 PPT 至少用一个独立讲解单元呈现“矩阵位置 → 共享输入 → 打包乘法 → 拆分 → 两路累加”，避免只给打包公式而缺少它与矩阵计算的对应关系。
