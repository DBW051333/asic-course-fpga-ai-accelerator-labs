# AX7020 平台优化 v1 实板结果

2026-10-12，从PS API v3独立派生，NPU/DMA/PL AXI统一166.667MHz，FC1保持192路、DSP212、模型不变。

|完整API|同轮v3|平台v1|中位数减少|
|---|---:|---:|---:|
|N=42|1.383 ms|1.397 ms|-0.98%|
|N=128|1.708 ms|1.710 ms|-0.10%|
|N=512|2.731 ms|2.648 ms|3.05%|
|N=1024|4.047 ms|3.900 ms|3.65%|
|N=2048|6.615 ms|6.267 ms|5.27%|
|N=4096|11.602 ms|10.944 ms|5.67%|

PL时间减少14.29%，理想吞吐提高16.67%；N2048/4096完整API达到至少5%目标，N42无测得收益。8块交替A/B，每点每版400次。WNS +0.049ns、WHS +0.050ns。

实板42/42正确、6804逐层特征一致；120秒33487个事务、3401688次重复样本，0错误。真实DMA超时及长度错误恢复通过。

ARM仍666.7MHz，DDR仍533.3MHz。ARM767MHz只生成离线PS配置XSA，未部署；DDR方向经事务周期分析暂缓，不能宣称DDR已调优。未尝试200MHz。

默认current_project.json与双基线/父版均保留。板端最后装载平台v1，原启动文件未改。
