# AX7020 256路复用实验

已完成独立工程 `lab8_ax7020_shared256_hybrid_v1`。选择打包编码特化Booth，220 DSP＋36路LUT乘法单元，FC1为256路/2组，三层共享同一阵列。单bank、原INT8模型、7 ns统一时钟。

相同核心测试口径：192路复用父版264周期→本版200周期，延迟减少24.24%。核心资源从9057 LUT / 22203 FF / 72 BRAM36 / 192 DSP增加为14782 LUT / 31155 FF / 96 BRAM36 / 220 DSP。完整PS＋DMA＋NPU系统：18764 LUT / 35919 FF / 100 BRAM36 / 220 DSP，WNS +0.255 ns、WHS +0.018 ns。

已通过逐层RTL、极值/随机输入和中断复位压力测试、原生UNISIM布线后功能仿真、实际AMD DMA IP仿真及完整AX7020实现。软件可读compute计数包含封装启动，为201周期，与核心testbench的200周期区分。

新硬件未上板，实际API耗时和功耗未测。512路与批量CMD3未实现。默认192工程与原指定128/256双基线保持，研究分支入口另存 `Lab8_baselines/shared_branch.json`。
